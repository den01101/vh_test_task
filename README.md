# VH Test Task

## 🚀 Installation

1. Clone the repository:

```bash
git clone git@github.com:den01101/vh_test_task.git
```

2. Install dependencies:

```bash
composer install
```

3. Configure environment variables (e.g. add your API key and base url):
```
WEATHER_API_KEY=your_api_key_here
WEATHER_BASE_URL=https://api.weatherapi.com
```

## 🌐 Running the Server
```bash
symfony server:start
# To stop the server:
symfony server:stop
```

## ✅ Running Tests
```bash
php bin/phpunit
```
